# КОНТАКТ

Одностраничная демонстрация сайта клининговой компании «КОНТАКТ».

## Структура

- `dist/index.html` — страница сайта
- `dist/styles.css` — адаптивные стили
- `dist/script.js` — мобильное меню, форма заявки с вложениями и листаемая галерея
- `dist/assets/` — локальные изображения

## Локальный просмотр

```bash
python3 -m http.server 4173 --directory dist
```

После запуска откройте `http://127.0.0.1:4173/`.

## Публикация

- Исходники: ветка `main`
- Статическая демонстрация: ветка `gh-pages`
- GitHub Pages: https://kibosh13.github.io/contact-klining/

Страница содержит директивы `noindex`, `nofollow` и `noarchive` для поисковых роботов.

## Форма заявки: демонстрационный режим

Кнопки «Написать», адрес `info@kontakt-clean.ru` и кнопки услуг открывают одно окно заявки.
Поля: имя, телефон, почта и комментарий без `maxlength`; можно добавить несколько документов,
посмотреть список и убрать отдельные файлы. Имя и телефон обязательны, почта необязательна.
Кнопка «Проверить заявку» проверяет поля и явно сообщает, что заявка не отправлена.

По согласованию с заказчиком от 24 октября 2026 года отправка отключена до настройки почты.
Форма не делает сетевых запросов, не сохраняет поля и файлы в localStorage, базе или Git.
Выбранные файлы существуют только в памяти вкладки. Атрибут `method="dialog"` также исключает
обычную отправку GET при недоступности JavaScript.

Для полноценного запуска нужен подтверждённый ящик `info@kontakt-clean.ru` и серверный обработчик
либо согласованный сервис форм с поддержкой вложений. GitHub Pages сам не отправляет письма.
При подключении необходимо реализовать серверную проверку и антиспам, передать `selectedFiles`
из `dist/script.js` через `FormData`, обработать ошибки и проверить фактическое получение письма
с вложениями. SMTP-пароли и ключи хранятся только на стороне обработчика, вне публичного репозитория.

## Галерея «Наши работы»

Каскадная горизонтальная галерея поддерживает свайп, стрелки и клавиши влево/вправо.
В демоверсии используются иллюстративные изображения с явной пометкой. После получения реальных
фотографий заменить `img` и подписи в `.work-slide`, затем убрать `.gallery-notice` и слово «Пример»
из альтернативных описаний. Примеры не обозначают реальные объекты партнёров.

## Адаптивные изображения

На ПК используется `hero-cleaning-hd.webp`, на телефонах до 680 px — отдельная вертикальная
композиция `hero-cleaning-mobile.webp` с тремя сотрудниками и надписями «КОНТАКТ» на форме.
В мобильной вёрстке фото и текст размещены отдельными блоками. Новые файлы для услуг:
`general-cleaning.webp` и `event-cleaning.webp`. Источники и промпты указаны в `ASSET_SOURCES.md`.
